OverdriveTuner - optimizador de PC para gaming (Windows 10/11, 64 bits)

INSTALAR
  1. Ejecuta OverdriveTuner-Setup.exe (acepta el aviso de administrador).
  2. Elige carpeta y accesos directos. Termina y abre OverdriveTuner.
  Instalación silenciosa: OverdriveTuner-Setup.exe /S

USAR
  - Inicio: escanea tu hardware y aplica el perfil Recomendado o Competitivo.
  - Cada ajuste tiene un interruptor: activarlo lo aplica; desactivarlo lo revierte
    a como estaba antes (se guarda una copia de cada valor en C:\ProgramData\FPSForge).
  - Los ajustes "Avanzado" bajan la seguridad: no están en ningún perfil.
  - Antes de aplicar un perfil se crea un punto de restauración.

DESINSTALAR
  Configuración > Aplicaciones > OverdriveTuner > Desinstalar.
  Los ajustes aplicados se mantienen: revierte antes los que no quieras.

COMPILAR (Go 1.22+, desde cualquier sistema):  ./build.sh

== Versión 2.7.5 ==
- Actualizaciones automáticas: el Setup tiene una casilla (marcada por defecto) para instalar solas las versiones nuevas que salgan en GitHub. El programa consulta solo GitHub (api.github.com), descarga OverdriveTuner-Portable.exe del último Release, comprueba su SHA-256 contra SHA256.txt del mismo Release y reemplaza el programa instalado; la versión nueva se usa al reiniciarlo (la ventana ofrece «Reiniciar ahora»). Se busca 25 segundos después de abrir y cada 6 horas, y también desde el overlay que arranca con Windows.
- Si la desactivás (en el Setup o en Configuración → Actualizaciones), no se consulta nada y el programa se queda en esa versión hasta que apliques el Parche. En Configuración hay además «Buscar actualizaciones» (a mano) y «Actualizar ahora».
- Instalaciones anteriores a 2.7.5 quedan con las automáticas desactivadas hasta que las actives.
- Solo funciona si en GitHub hay un Release estable (no pre-release) con el tag vX.Y.Z y los archivos OverdriveTuner-Portable.exe y SHA256.txt. Los archivos de las actualizaciones no tienen firma digital: la confianza es la cuenta de GitHub del proyecto más el SHA-256.
- El desinstalador también borra los restos del actualizador (copias «.old», carpeta «update»).
- Se quitó PresentMon por completo (ya no se incluye en el programa).
- Sin probar aún en Windows real: la descarga y el reemplazo se probaron con tests automáticos y un servidor falso.

== Versión 2.8.0 ==
- Diagnóstico: chequeos nuevos. Resizable BAR (solo se puede medir en NVIDIA con nvidia-smi; en Radeon se explica cómo verlo), antigüedad del driver de la gráfica (aviso desde 9 meses, con botón a la página oficial de NVIDIA/AMD/Intel), salud/desgaste/temperatura de cada disco (Windows lo expone solo en algunos discos), espacio libre del disco de Windows y una guía de ajustes de BIOS.
- Herramientas > «Ping a servidores de juegos»: mide el tiempo de conexión TCP (puerto 443) hacia servicios de juegos y regiones de AWS. No es el ping exacto de una partida (los servicios usan CDN); las regiones dan mejor idea de la distancia. La pérdida se estima por conexiones fallidas.
- Configuración > Tareas programadas: limpieza semanal (solo objetivos seguros) y punto de restauración semanal, con día y hora a elección. Usan el Programador de tareas de Windows (OverdriveTuner.exe --task cleanup|restore), con permisos de administrador y solo con la sesión iniciada; si la PC estaba apagada, corren al encenderla. El desinstalador las quita.
- Sin probar aún en Windows real: los scripts de PowerShell nuevos y las tareas programadas se probaron solo con tests y en modo demostración.
